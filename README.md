## 📚 Sobre o Projeto

Este é um livro gratuito e em constante evolução sobre Linux, escrito em português. O objetivo com este projeto é facilitar o aprendizado de Linux para q
ualquer pessoa, criando um material simples e direto, que parte do hardware até chegar ao sistema operacional propriamente dito.

O Linux possui livros incríveis e muita documentação, porém parte desse material é paga e outra parte ainda está disponível apenas em PDF. Este projeto b
usca contribuir com a comunidade oferecendo conteúdo moderno, estruturado e gratuito em português.

Acesse: <https://linux-v0-1-book.vercel.app/>

## 🎯 Para Quem é Este Livro?

- Pessoas que estão começando no Linux e querem entender o sistema desde a base;
- Usuários de Windows ou macOS migrando para o Linux;
- Quem quer compreender o hardware por trás do sistema operacional, não apenas os comandos.
