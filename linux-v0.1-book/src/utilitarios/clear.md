# clear

Limpa a tela do terminal.

```bash
clear
```

| Argumento / Opção | Descrição |
|---|---|
| (nenhum) | O comando `clear` não recebe argumentos ou opções |

> Atalho de teclado equivalente: `Ctrl + L`.

**Exemplos**

```bash
clear                                # limpa a tela do terminal
```
